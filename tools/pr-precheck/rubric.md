# Rubric: is this pull request ready to submit?

## Checks

| Check | Evidence | Pass condition | Weight |
|---|---|---|---|
| Plan fidelity | Plan scope pair, intended behavior and test plan, explicit deviations, changed files/hunks and description scope claims; see Plan fidelity in the evidence guide. | Every delivered behavior and changed hunk implements the issue-bound plan or a recorded, issue-related deviation. Any planned behavior intentionally left out is explicitly identified in both the updated plan and description. An honestly narrowed, demonstrated change can pass; silent extra behavior or omitted scope cannot. | required |
| Issue-specific proof | Reproduction steps and expected-after in the plan read beside the test-evidence before/after, commands, assertions and actual diff. | Evidence names the trigger and observable failing-before and fixed-after outcomes for the delivered behavior, exercising the affected implementation rather than merely a substitute mock. Cover the plan's promised scenarios unless an explicit plan/description deviation narrows the delivered scope. A suite total alone, a proposed test, or an assertion that never distinguishes the bug fails. | required |
| Repo check evidence | Repo-facts required checks or live template/CONTRIBUTING check list, paired with commands, recorded output/outcomes and description checkboxes. | Every explicitly requested applicable repo check has a recorded attempt and outcome. An equivalent invocation must be explained. An honestly reported failure or expected no-tests result can pass this evidence check when its reason and remaining limitation are disclosed; an omitted check or unsupported all-green claim cannot. Do not impose checks the repo never asks for. | required |
| Reviewable diff | Complete unified diff and commit list, read against the issue and plan boundary. | The fix and its necessary tests, dependencies or docs can be identified without unrelated edits, temporary debug output, commented-out implementation, dead scaffolding or bulk formatting churn. Related supporting changes pass; explaining an unrelated cleanup does not make it related. | required |
| Faithful claims | Title, description and checked boxes compared with diff, plan/deviations and actual test outputs. | Every factual claim is supported: stated coverage, delivered scope and test/CI outcomes match the artifacts. Known shortfalls are named rather than hidden. A disclosed partial result can pass; calling incomplete coverage complete or unrun checks successful fails. | required |
| Stated standards | Repo-facts template, CONTRIBUTING, policy and maintainer asks in the thread, paired with candidate description; live scope house rules and course disclosure requirement. | Honor each explicit applicable ask with actual content, including issue reference, required template sections and conditional AI disclosure. N/A needs an applicable reason. In live course mode name AI tools and their extent in Notes for Reviewers, use the scoped fork/branch rules, and do not duplicate the student's existing PR. In eval mode use only the bundle's stated policy: when it requires disclosure, silence is not a no-AI statement; an explicit, uncontradicted no-AI statement satisfies a conditional policy. If the repo has no template or disclosure ask, do not invent one. | required |
| Regression control | Additional control/error-path assertions and repo-check outcomes alongside the delivered behavior. | At least one relevant unaffected or failure-path behavior is observed as still working, in addition to the decisive issue-specific proof. Missing a control is a preferred shortfall, not a submission gate. | preferred |

## Verdict rule

Accept only when every required check is pass. Any required fail or unclear produces reject; preferred grades never change the verdict. Grade all rows even after finding a failure. For absent required evidence use fail; for unavailable or contradictory evidence that cannot be resolved from the allowed sources use unclear. A disclosed failure does not erase missing attempts or false claims, but an honest scoped outcome is not rejected merely for doing less than the original ambition.
